# 📚 AI Study Assistant

A simple AI-powered study assistant that answers questions using your study notes.

## 🚀 Features

- Ask questions about your study notes
- Uses a local AI model
- No OpenAI API credits required
- FastAPI backend
- Simple HTML/CSS/JavaScript frontend
- Runs locally using Ollama

## 🛠️ Technologies

- Python
- FastAPI
- Ollama
- Llama 3.2
- HTML
- CSS
- JavaScript
